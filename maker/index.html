Why there are no sliders on this page

The configurator is an .scad script, not a web app. GitHub Pages only serves files; it cannot run an OpenSCAD kernel. The sliders, dropdowns and SVG upload fields you know are created by MakerWorld's Parametric Model Maker from special comments such as // [20:0.5:100] and // @type: file. A browser treats those as ordinary comments.

So this page does the lossless thing: it stores the script byte-for-byte, documents it, and links out to the real generator. Rebuilding the Customizer in the browser would mean rewriting the UI, bundling roughly 19 MB of WebAssembly, and losing the platform's font, colour and 3MF multi-material behaviour.

Ask an AI to customise the script

Use this when you want a new shape, a different attachment, or an extra parameter added to the Customizer. Copy it into any AI assistant, then paste your request at the end.

ROLE
You are editing one OpenSCAD file written for MakerWorld Parametric Model Maker:
3dream-nfc-keychain.scad (3DREAM Ultimate NFC Keychain Configurator).

HARD RULES
1. Treat the file as read-only except for the exact change I ask for. Do not
   reformat, reorder, rename or "clean up" anything else. Show me the exact
   lines to replace plus a short diff.
2. Keep every magic comment attached to its variable:
   // [min:step:max], // [A,B,C], // [Label:Value], // font,
   // @type: file, // @extension: svg, // @label: ...
   MakerWorld parses these comments to build the Customizer UI. Changing them
   silently breaks the sliders and the SVG upload fields.
3. Keep /* [Hidden] */, every module definition and the final
   union() / difference() assembly unchanged unless I explicitly ask for a
   geometry change.
4. Stay compatible with the OpenSCAD 2021 stable release. Do not use
   development-snapshot-only features.
5. Only fonts installed on MakerWorld are valid. The existing Global_Font
   dropdown lists the supported ones. Do not invent a font name.
6. STL has no color. color() only affects the preview and MakerWorld's 3MF
   pipeline. Never promise that a color change will appear in an STL.
7. Any import() file must be a simple SVG made of <path> elements using
   M / L / Z / C / A commands. Avoid <rect>, <circle>, <text>, CSS and
   external references.
8. Never ask me for passwords, tokens, verification codes or any credential.

CONTEXT
- 9 parameter groups: Main Body, NFC Cavity, Attachment, Typography,
  Global Movement, Front SVG, Back SVG, Front Texts, Back Texts.
- 8 text lines: T1..T4 on the front, T5..T8 on the back. Each has
  _Txt, _X, _Y, _Size, _Rot, _D (engrave), _E (emboss), _Col.
- Front_SVG and Back_SVG default to "default.svg" and must be uploaded
  through the Customizer's file control before the script can render.
- element_cut() engraves, element_emboss() raises; both are called once per
  front element and once per back element inside the final assembly.

MY REQUEST
<describe exactly what you want changed, including parameter names and target
values, and say whether you want a new control added to the Customizer>

BEFORE YOU ANSWER
Ask one or two clarifying questions if anything is ambiguous. Then give me the
minimal patch, tell me which Customizer controls will change, and list anything
that could break the 3MF export.

About this page

What it is for

It is a permanent home for the 3DREAM configurator source and a checklist for the day you want to print your own version of the NFC keychain. The script itself is unchanged — you download it and run it in the generator you already use. Nothing here depends on this page staying online except the documentation.

Which prompt to use

Use the copyable prompt above when you want the script changed: a new shape, a new attachment style, an extra parameter in the Customizer. Use the prompt in the NFC tap setup guide when you want to publish a web page and write its URL to a tag. They solve different problems.

How to get the software on your phone

There is nothing to install for generating the model — open Parametric Model Maker in Safari or Chrome on your phone and sign in. For the tag itself, install NFC Tools from the App Store or Google Play, then use Write → Add a record → URL. If you also want to preview the geometry offline, install desktop OpenSCAD on a computer; the 2021 stable release matches MakerWorld best.

FAQ & known limits

What is default.svg and why do I need it?

The script sets Front_SVG = "default.svg" and Back_SVG = "default.svg", and both are used by import(). On MakerWorld the // @type: file control replaces those strings with whatever SVG you upload. The default.svg shipped here is a tiny single-path placeholder: upload it as a smoke test, or put it next to the .scad when running OpenSCAD locally. If no SVG is available, import() fails and the model will not render.

Why can't this page generate the model directly?

GitHub Pages serves static files only. OpenSCAD must be compiled by a CAD kernel; the sliders come from magic comments that only MakerWorld / the OpenSCAD Customizer parses. Running OpenSCAD in the browser is possible with a WebAssembly build, but that means rebuilding the entire Customizer UI by hand, shipping a large WASM binary, and still losing the platform's colour, font and 3MF multi-material behaviour. We deliberately chose the lossless route.

My colours disappeared in the exported file

Expected. color() in OpenSCAD is a preview property; STL stores geometry only and has no colour. MakerWorld's 3MF flow can carry colour / multi-material when the model is generated through its Customizer. For a two-colour print from desktop OpenSCAD, use a filament change at a layer height or paint the embossed details after printing.

Which fonts can I use?

Only fonts installed on MakerWorld's servers (mostly Google Fonts). The script's Global_Font dropdown already lists the ones it was designed for: Arial Bold, Arial Regular, Courier New Bold, Times New Roman Bold and Impact. When running locally, those fonts must exist on your machine too.

The model will not render / the SVG looks wrong

Check three things: (1) both front and back SVG file controls have a file; (2) the SVG uses only <path> geometry with M/L/Z/C/A commands — no <text>, no CSS, no external images; (3) the scale is sensible — the default 0.15 makes a 40-unit drawing about 6 mm wide. Setting FSVG_Depth or FSVG_Emboss to 0 disables that operation.

Is the .scad really unchanged?

Yes. It is stored byte-for-byte as authored: 339 lines, 11,770 bytes. Use the "Verify the source is byte-for-byte" control in step 1 to compute the fingerprint of the file your browser actually received. This page only adds files under /maker/; it does not read or modify the card page, its config, the editor, or /start/.

Can I embed the MakerWorld Customizer here with an iframe?

Not reliably. There is no documented, stable embeddable Customizer widget or share link with preset parameters, and cross-origin plus sign-in state get in the way. A plain external link is the dependable option.
